# Altiora — Product Ideas

Ideas surfaced while building the MVP. Each has a one-line rationale and a rough
effort estimate (**S** = days, **M** = a week or two, **L** = multi-week /
needs infra or ML). Grouped by theme.

---

## Intern delight

- **Prefill skill ratings from last week** ✅ **SHIPPED** (refinement pass) —
  _continuity: interns adjust a baseline instead of re-rating from a default 3,
  which is faster and truer._ **S**
- **Reflection templates / prompts** — _rotating prompts beat a blank box and
  raise the quality of qualitative reflection._ **S**
- **Learning streaks & gentle gamification** — _a visible streak (already
  computed) plus soft milestones nudges the weekly habit without pressure._ **S**
- **End-of-internship growth report / certificate** — _a shareable artifact of
  the journey — skills gained, top learnings, trend charts — is a strong closing
  moment._ **M**

## Mentor coaching

- **Mentor analytics** — _surface which mentors drive the most measurable growth
  so coaching itself can be coached._ **M**
- **Goal tracking that carries forward** — _each week's "next goal" auto-appears
  next week to check against; turns reflection into a loop._ **M**
- **Peer visibility (optional, opt-in)** — _let interns optionally see anonymized
  peer reflections for normalization and inspiration._ **M**

## Org intelligence

- **AI weekly summary of each reflection** — _a one-paragraph synthesis per
  intern per week saves mentors reading time and sharpens focus._ **M**
- **Burnout early-warning** — _flag declining mood + rising hours + falling
  confidence trends before they become attrition._ **L**
- **Sentiment analysis on qualitative text** — _quantify tone in free-text
  reflections to complement the numeric signals._ **M**
- **"Source effectiveness" as an org insight** — _promote the existing metric
  (which learning sources actually move skills) into a headline org view._ **S**
- **Cross-cohort benchmarking** — _compare cohorts on growth, completion, and
  confidence to spot what a good program looks like._ **M**
- **Competency framework / skill matrix** — _map skills to leveled competencies
  so growth reads against a shared rubric, not just raw scores._ **L**
- **Per-project learning attribution** — _learning logs already link to
  projects; roll up to show which projects teach the most._ **S**
- **Manager / department rollups** — _aggregate growth and engagement up the org
  tree for leadership._ **M**
- **Knowledge base auto-built from high-impact learning logs** — _the best
  learnings become a searchable, compounding internal resource._ **L**

## Growth loops

- **Streak nudges + weekly reminder notifications** — _a well-timed reminder is
  the single highest-leverage lever on weekly completion._ **M**
- **Goal → reflection → next-goal loop** — _(see goal tracking) closing the loop
  each week is what converts a form into a growth practice._ **M**
- **Skill velocity tracking** — _rate-of-change on skills, not just levels,
  spotlights momentum and stalls early._ **M**
